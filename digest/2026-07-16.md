### [LangBot: Authenticated RCE Via MCP Configuration](https://github.com/advisories/GHSA-3pvh-63gf-j9mw)
*GitHub Security Advisories · 19h ago · score 92*

LangBot allows authenticated users to achieve remote code execution by configuring arbitrary STDIO-based Model Context Protocol (MCP) servers through the Extensions interface, enabling complete machine compromise via subprocess execution. This vulnerability requires authentication but represents a critical post-auth RCE risk in LangBot deployments, particularly for instances exposed to untrusted networks or with weak credential controls.

### [GDM AI Control Roadmap](https://arxiv.org/abs/2607.13087)
*arXiv cs.CR · 9h ago · score 92*

This paper introduces the GDM AI Control Roadmap, a comprehensive framework for internal security controls against potentially misaligned AI agents through threat modeling (TRAIT&R taxonomy), capability-based tiered defenses (D1-D4 detection, R1-R3 prevention/response), and 15 concrete mitigations. The work directly addresses a critical gap in AI security by establishing operational guidelines for defending internal systems against hypothetical AI adversaries as agentic systems become more deeply integrated into organizational infrastructure.

*The Hacker News · 1h ago · score 92*
