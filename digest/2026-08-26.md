### [TrustShiftProbe: Characterizing, Benchmarking, and Defending Staged Trust Attacks on MCP Servers](https://arxiv.org/abs/2608.23763)
*arXiv cs.AI · 8h ago · score 92*

TrustShiftProbe identifies a novel temporal attack vector against MCP servers where a compromised server behaves benignly during initial conditioning before switching to adversarial payloads once trust is established, evading both static analysis and runtime filters. The research introduces a threat model, attack engine, and SHIELD defense framework to characterize, benchmark, and mitigate these staged trust attacks that originate from the trusted server endpoint itself rather than user prompts or transport layer.

### [Beyond the Mandate: A Systematic Security Analysis of the Agent Payments Protocol (AP2)](https://arxiv.org/abs/2608.23858)
*arXiv cs.AI · 8h ago · score 92*

This systematic security analysis of Google's Agent Payments Protocol v0.2 identifies 48 threats across 11 attack surfaces affecting LLM-driven shopping agents, with 8 reaching high severity in specific architectures. The research demonstrates practical exploitation of payment authorization mechanisms through agent interactions and tool calls that bypass cryptographic protections, directly impacting the security of AI-driven financial transactions.

### [Chainlit has command injection via MCP stdio transport that allows unauthenticated remote code execution](https://github.com/advisories/GHSA-w3fx-mc44-mf6j)
*GitHub Security Advisories · 17h ago · score 92*

Chainlit's MCP stdio transport endpoint allows unauthenticated remote code execution through command injection in the fullCommand parameter, bypassing the allowlist validation by injecting shell metacharacters into arguments rather than the executable name. This critical vulnerability (CVE-2026-45018) affects versions 2.4.0rc0 through 2.7.3 when MCP is explicitly enabled, requiring no authentication and allowing arbitrary code execution with Chainlit process privileges.

### [mcp-contextforge-gateway has Server-Side Template Injection (SSTI) leading to Remote Code Execution in `PromptService._render_template` via unsandboxed Jinja2 Environment](https://github.com/advisories/GHSA-vwf3-4xxj-qg6h)
*GitHub Security Advisories · 18h ago · score 92*

mcp-contextforge-gateway contains a critical Server-Side Template Injection (SSTI) vulnerability in its PromptService that uses unsandboxed Jinja2 Environment, allowing authenticated users to execute arbitrary Python code on the gateway host. This affects all published versions including 0.9.0 and represents a direct path to remote code execution for attackers with prompt template registration/update permissions.
