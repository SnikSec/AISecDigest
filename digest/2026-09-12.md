*GitHub Security Advisories · 18h ago · score 92*

The mysql_mcp_server's SSE/HTTP transport mode lacks origin/host validation and authentication, allowing unauthenticated SQL execution via direct network access or DNS rebinding attacks. This enables arbitrary SQL execution with full database compromise, file read/write, and potential RCE through MySQL FILE privileges.

### [Spectral Masking and Interpolation Attack (SMIA): A Black-box Adversarial Attack against Voice Authentication and Anti-Spoofing Systems](https://arxiv.org/abs/2509.07677)
*arXiv cs.AI · 10h ago · score 92*

SMIA is a novel black-box adversarial attack that manipulates inaudible frequency regions in AI-generated audio to deceive voice authentication systems and anti-spoofing countermeasures, achieving 82-100% attack success rates depending on the target system. This research exposes critical vulnerabilities in currently deployed voice authentication systems used in banking and healthcare, demonstrating that static detection models are insufficient against adaptive adversarial techniques.
