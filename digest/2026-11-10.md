## Offensive Security & AI Workloads (1)

### [fast-agent: `fast-agent serve` binds HTTP to 0.0.0.0 with no authentication by default; with --shell this is unauthenticated remote command execution](https://github.com/advisories/GHSA-9vhv-g5hf-m7m7)
*GitHub Security Advisories · 21h ago · score 95*

The fast-agent library's serve command exposes an MCP agent over unencrypted HTTP bound to 0.0.0.0 with no authentication by default, creating an unauthenticated remote code execution vulnerability when the --shell flag is used (as in the official README quickstart). Any attacker with network access can trigger arbitrary OS command execution through the exposed shell tool, making this a critical severity issue for any deployment following the documented quick-start guidance.
