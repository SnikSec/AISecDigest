### [LLM Misuse Safeguards Rely on Untrusted Input: A Widespread, High-Risk Vulnerability](https://arxiv.org/abs/2607.27951)
*arXiv cs.AI · 14h ago · score 95*

This paper reveals that LLM misuse safeguards fundamentally rely on trusting user-provided identity claims without verification, creating a widespread vulnerability that all 129 proposed defenses in top venues share. Attackers can bypass safety mechanisms by simply fabricating professional credentials, and existing benchmarks fail to detect this flaw because they don't distinguish between legitimate and malicious actors making identical requests.

### [mssql-mcp-core: SQL injection in mssql-mcp write tools via unparameterized table names and WHERE clauses](https://github.com/advisories/GHSA-2m9m-6cr5-9x25)
*GitHub Security Advisories · 18h ago · score 92*

The mssql-mcp-core package contains critical SQL injection vulnerabilities across multiple tools that interpolate user-supplied table names, column names, and WHERE clauses directly into T-SQL queries without parameterization. This allows attackers to inject arbitrary SQL commands, potentially exfiltrating sensitive data or modifying database contents through compromised MCP clients.

## AI Identity & Non-Human Identity (1)

### [ACaM: Automated Capability Modeling for Agentic AI Security](https://arxiv.org/abs/2611.23507)
*arXiv cs.CR · 14h ago · score 82*

ACaM introduces a neurosymbolic approach to detect "capability laundering"—where tool implementations contain undisclosed dangerous behavior hidden behind benign descriptions—by deriving actual capabilities from code rather than trusting natural language descriptions. This addresses a critical security gap in deployed agentic AI systems where Description-Code Inconsistency (DCI) enables tools with standing access to credentials and sensitive data to perform unintended operations.
