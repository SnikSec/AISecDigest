*GitHub Security Advisories · 17h ago · score 85*

The mcp-atlassian library's confluence_upload_attachment function lacks path validation, allowing authenticated MCP clients (or AI agents via prompt injection) to read and exfiltrate arbitrary files accessible to the server process. This vulnerability is especially critical in agentic deployments where prompt injection could trick an LLM-powered agent into uploading sensitive credentials or configuration files to Confluence.
