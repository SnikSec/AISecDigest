### [Containing the Autonomous Operator: A Defense-in-Depth Framework and Reference Architecture for Securing AI Agents on Kubernetes](https://arxiv.org/abs/2610.02861)
*arXiv cs.CR · 16h ago · score 92*

This paper presents a comprehensive defense-in-depth framework for securing LLM-based agents operating on Kubernetes infrastructure, treating the agent model as untrusted and vulnerable to prompt injection attacks. The work provides a threat taxonomy, design principles, and practical reference architecture leveraging native Kubernetes security mechanisms (RBAC, admission policies, sandboxing, egress controls) to prevent agent compromise from cascading into cluster compromise.

### [Evaluating and Improving the Robustness of Large Language Models to Input Sequence Variations](https://arxiv.org/abs/2610.02432)
*arXiv cs.CR · 16h ago · score 82*

This arXiv research evaluates LLM robustness to adversarial input variations including prompt injections, trojans, and metric manipulation, proposing metrics like R_stab(f) and attacks like ASA that achieve 73.8% success rates against LLM-as-a-Judge systems. The work demonstrates practical defenses including ensemble methods, multi-layer bypass detection, and AttestMCP for securing agentic systems with tool call attestation, providing critical insights for production LLM security hardening.

### [Persona Guardrail: A Production-Grade Defense Framework for Agentic Systems](https://arxiv.org/abs/2610.03434)
*arXiv cs.CR · 16h ago · score 82*

Persona Guardrail is a production-deployed runtime defense framework that enforces functional boundaries for LLM-based agents through semantic allowlist/blocklist validation, improving guardrail accuracy from 85.7% to 95.9% and out-of-domain detection from 57.3% to 93.5%. The work addresses a critical gap in agentic AI security by moving beyond black-box prompt-injection defenses to ensure agents operate within intended functionality boundaries, with results validated against a new PAGE benchmark across adversarial and out-of-domain scenarios.

### [Why Backdooring Neural Networks is so Easy?](https://arxiv.org/abs/2609.36117)
*arXiv cs.CR · 16h ago · score 82*

This theoretical analysis reveals that neural networks' feature-learning capabilities—which enable their power—paradoxically make them more vulnerable to backdoor attacks, requiring significantly lower trigger strengths for successful poisoning at small poison fractions. The research provides closed-form mathematical bounds showing that feature learning reduces required trigger strength from O(π^-1/2) to O(π^-1/4), explaining why empirical observations show LLMs can be backdoored with relatively few malicious samples despite large clean datasets.
