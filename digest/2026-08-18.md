### [atomic-agents-stack: HTTP MCP catalog accepts cleartext http and spawns catalog-supplied commands (MITM to RCE)](https://github.com/advisories/GHSA-xhcr-cqfr-m3hv)
*GitHub Security Advisories · 14h ago · score 92*

The atomic-agents-stack's HTTP MCP catalog accepts cleartext HTTP URLs and spawns arbitrary commands from catalog entries without validation, enabling MITM attackers to inject malicious commands and achieve RCE with no LLM involvement. This affects all versions through 1.0.0 where the Policy MCP allowlist is not enabled by default, leaving agents vulnerable unless operators explicitly configure security controls.

### [Proof-of-Execution Memory: Defending LLM Agents Against Forged-Reasoning Attacks by Verifying What Actually Happened](https://arxiv.org/abs/2608.16032)
*arXiv cs.CR · 8h ago · score 92*

This paper reveals critical vulnerabilities in LLM agent memory systems where adversaries can insert fabricated reasoning entries to bypass safety steps, with existing defenses (SENTINEL) easily circumvented through simple rewording attacks. The proposed Proof-of-Execution Memory (PoEM) solution uses cryptographic ledgers to track actual execution rather than trusting memory contents, addressing a fundamental architectural weakness in stateless agent designs that worsens with model capability.

### [SkillWatermark: An Embedded Skill Watermark of Progressive Privacy Inference via Benign Prompts](https://arxiv.org/abs/2608.16026)
*arXiv cs.CR · 8h ago · score 82*
