### [AutoPI: Taxonomy-Guided Adaptive Red Teaming for Prompt Injection in LLM Agents](https://arxiv.org/abs/2611.24313)
*arXiv cs.AI · 14h ago · score 82*

AutoPI is an adaptive red-teaming framework that systematically discovers diverse prompt-injection attack vectors against LLM agents by maximizing technique coverage rather than just attack success rate, using a taxonomy of injection methods to guide exploitation. This research is critical for security practitioners because it demonstrates that ASR-optimized red teamers may miss important attack classes, and introduces a training-free, black-box methodology that could significantly improve the comprehensiveness of LLM agent security evaluations.

## AI Identity & Non-Human Identity (2)

### [Jupyter MCP Server: Unauthenticated management routes can hijack the Jupyter backend in standalone HTTP mode](https://github.com/advisories/GHSA-24pw-rf5p-mgp7)
*GitHub Security Advisories · 19h ago · score 92*

Jupyter MCP Server's standalone HTTP mode exposes unauthenticated management routes (`PUT /api/connect`, `DELETE /api/stop`) that bypass the documented token authentication requirement, allowing an attacker to hijack the kernel client and redirect it to attacker-controlled infrastructure. This directly contradicts the security documentation which explicitly states all MCP endpoints require Bearer token authentication, creating a critical authentication bypass vulnerability.

### [Why Trust Your Agent? Empirical Security Gains from TRiSM-Guided Agentic Workflows in Healthcare](https://arxiv.org/abs/2606.28666)
*arXiv cs.CR · 14h ago · score 82*

This paper demonstrates how applying TRiSM (AI Trust, Risk, and Security Management) framework to agentic LLM workflows reduces attack success rates significantly—from 31% to 10% for RAG poisoning and 42% to 25% for data-field injection—while improving report accuracy. The work highlights critical security gaps when agents are granted excessive access rights and validates that least-privilege architecture and security-conscious workflow redesign substantially mitigate agent-based threats in healthcare settings.
