## AI Security (4)

### [Understanding and Enhancing Backdoor Persistency in LLM Agent Post-Training](https://arxiv.org/abs/2610.07510)
*arXiv cs.CR · 14h ago · score 92*

This research demonstrates a critical supply-chain vulnerability where backdoors inserted into third-party LLM models can persist through benign post-training and reinforcement learning processes, with attackers able to deliberately enhance persistence via the PersistBD technique. Security practitioners must implement robust detection mechanisms when adopting third-party models, as standard fine-tuning practices provide insufficient protection against inherited backdoor attacks in agent deployments.

### [Unpatched Critical LMCache Flaw Lets Unauthenticated Attackers Run Code Remotely](https://thehackernews.com/2026/10/unpatched-critical-lmcache-flaw-lets.html)
*The Hacker News · 2h ago · score 92*

A critical unauthenticated remote code execution vulnerability in LMCache allows attackers to execute arbitrary code on cache servers without authentication, with no patch currently available. This impacts LLM infrastructure deployments using vLLM and other systems relying on LMCache's multiprocess mode via ZeroMQ, representing a severe supply-chain risk for LLM service providers.

### [APEX: Active Protection at Execution Boundaries for LLM Agents](https://arxiv.org/abs/2610.06966)
*arXiv cs.AI · 14h ago · score 85*

APEX proposes a defense mechanism that protects LLM agents against indirect prompt injection (IPI) attacks by enforcing authorization contracts at execution boundaries, using evidence-gating and deception-based exposure to prevent unauthorized actions regardless of how the injection propagates through diverse capability units. The approach achieves near-perfect attack prevention (0% success on most benchmarks) while moving beyond traditional pattern-matching defenses to a unified mechanism that applies uniformly across Tools, MCP servers, and Skills.

### [Does On-Policy Distillation for Safety Pose Backdoor Risks?](https://arxiv.org/abs/2610.07654)
*arXiv cs.AI · 14h ago · score 82*

On-policy distillation (OPD), increasingly used for LLM safety alignment, can propagate backdoored behavior from a malicious teacher model to a clean student model with poisoning rates as low as 3%. The research identifies specific training choices (extended epochs, top-k KL divergence) that amplify backdoor transfer risk and proposes a mitigation strategy (Lazy Defense) to slow this propagation.

### [HarnessSecurity-Bench: Do Security Mechanisms Really Protect Coding Agent Harnesses?](https://arxiv.org/abs/2610.07639)
*arXiv cs.CR · 14h ago · score 92*

This paper presents a systematic empirical evaluation of security mechanisms in coding agent harnesses, finding that roughly half of mechanisms are opt-in and some security settings like auto-approve dramatically increase attack success rates (from 29.2% to 95.6%). The work introduces HarnessSecurity-Bench with 2,500 trials across leading harnesses (Claude, Codex, Gemini, gptme, etc.), providing critical security posture benchmarking for deployed agentic systems that authorize tool execution.
