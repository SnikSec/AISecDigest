*arXiv cs.CR · 8h ago · score 92*

### [Toward Metacognitive One-Shot Indirect Prompt Injection: Strategy Abstraction Via Outcome-Conditioned Reflection](https://arxiv.org/abs/2608.08795)
*arXiv cs.CR · 8h ago · score 85*

SAVOR demonstrates a novel one-shot indirect prompt injection attack against LLM agents that uses outcome-conditioned reflection to distill reusable attack strategies offline, achieving significantly higher success rates than existing methods without requiring multiple target queries. This research is critical for security practitioners as it reveals that LLM agents are vulnerable to single-opportunity attacks with high effectiveness, escalating the threat model beyond iterative adaptive attacks and requiring new defensive measures.
