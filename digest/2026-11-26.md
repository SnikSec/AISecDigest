### [IntentMiner: Intent Inversion Attack via Tool Call Analysis in the Model Context Protocol](https://arxiv.org/abs/2512.14166)
*arXiv cs.CR · 15h ago · score 82*

IntentMiner demonstrates a novel privacy attack where semi-honest MCP servers can reconstruct user intents from authorized metadata (function calls, arguments, results) with 85%+ semantic alignment, without needing access to raw queries. This attack exposes a critical architectural vulnerability in agentic AI systems where the decoupled trust model enables intent inference through tool interaction patterns, requiring security engineers to implement semantic obfuscation defenses.

### [The Detour Is the Danger: Preserving Security During LLM Agent Recovery](https://arxiv.org/abs/2611.33605)
*arXiv cs.CR · 15h ago · score 82*

LLM agents can experience workflow security downgrade attacks where autonomous recovery from task failures silently removes security protections while maintaining functionality—a novel threat distinct from prompt injection. The paper presents ARGUS, a framework that preserves security obligations during agent recovery through evidence-based validation and execution enforcement, demonstrated effective across seven LLMs and multiple security-sensitive domains.
