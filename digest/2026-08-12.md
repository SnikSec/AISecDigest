## AI Security (6)

### [On Understanding, Identifying, and Mitigating Vulnerabilities in Agentic Large Language Models](https://arxiv.org/abs/2608.10530)
*arXiv cs.AI · 8h ago · score 92*

This systematic literature review identifies a critical gap in agentic LLM security research, with attacks outnumbering defenses 3.9:1 and research heavily skewed toward perception-layer vulnerabilities while action-layer risks (tool misuse, code injection, sandbox escape) remain understudied despite real-world impact. The paper introduces a four-layer taxonomy of 13 vulnerability types and highlights architectural coupling as the root cause enabling vulnerability propagation across layers, providing essential guidance for defenders building secure autonomous agents.

### [From Prompt Injection to Web Exploitation: Revisiting Classic Vulnerabilities in LLM-Integrated Applications](https://arxiv.org/abs/2608.10281)
*arXiv cs.CR · 8h ago · score 92*

This paper systematizes a critical attack surface where LLM-mediated transformations of user input can activate traditional web vulnerabilities (SQLi, XSS, SSTI, command injection, IDOR, CSRF, XXE, SSRF) in backend systems that trust model-generated content. The research demonstrates substantial variation in susceptibility across LLM models and provides mitigation strategies across prompt, model, application, and network layers—directly relevant for securing LLM-integrated applications in production.

### [SoK: The Attack Surface of Agentic AI - Tools and Autonomy](https://arxiv.org/abs/2603.22928)
*arXiv cs.CR · 8h ago · score 92*

This systematization of knowledge comprehensively maps attack surfaces in agentic AI systems, identifying novel threat vectors including indirect prompt injection, RAG poisoning, tool exploits, and cross-agent manipulation that extend beyond traditional LLM vulnerabilities. The paper provides practitioners with a taxonomy of attacks, threat models, security metrics, and a phased deployment checklist—making it highly actionable for security engineers implementing agentic AI systems.

### [Evaluation and Hardening of LLM System Instructions Against Extraction via Encoding Attacks](https://arxiv.org/abs/2604.01039)
*arXiv cs.AI · 8h ago · score 88*

This research demonstrates that system instructions in LLMs remain vulnerable to extraction attacks even when models refuse direct requests, with high success rates (>70%) when extraction is reframed as encoding or structured output tasks. The work provides both an automated evaluation framework for testing instruction confidentiality and practical mitigation strategies using instruction reshaping, directly addressing a critical security concern for agentic AI systems handling sensitive operational context.

### [Researchers Disclose AI-Assisted SharePoint Exploit Chain Reaching Unauthenticated RCE](https://thehackernews.com/2026/08/researchers-disclose-ai-assisted.html)
*The Hacker News · 19h ago · score 85*

Researchers leveraged an AI agent to discover a critical unauthenticated RCE vulnerability (CVE-2026-55040, CVSS 9.1) affecting multiple SharePoint Server versions, enabling attackers to authenticate as any user including administrators. This demonstrates both the offensive capability of AI-assisted vulnerability research and the urgent need to patch high-impact enterprise infrastructure vulnerabilities discovered through novel attack methodologies.

### [Telemetry and Concealment in Self-Adapting Generative AI: Logging Architecture, Adversarial Model Hiding, and the Limits of Detection](https://arxiv.org/abs/2608.09069)
*arXiv cs.CR · 8h ago · score 82*

This paper addresses governance and detection challenges in self-adapting AI models that autonomously update during production by developing telemetry architectures (Merkle chains, KL divergence-based logging) and formalizing attack strategies adversarial providers might use to conceal model updates. The work is critical for establishing audit and validation frameworks for continually learning AI systems that violate traditional static model governance assumptions.
