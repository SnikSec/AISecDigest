## AI Security (4)

### [Toward Secure LLM Agents: Threat Surfaces, Attacks, Defenses, and Evaluation](https://arxiv.org/abs/2606.10749)
*arXiv cs.AI · 8h ago · score 92*

This comprehensive survey synthesizes 247 papers on LLM agent security, introducing a lifecycle-based framework that models threats around information flow, delegated authority, and persistent state—critical as agents move beyond text generation to control tools and external environments. The analysis reveals that prompt injection and tool-mediated control-flow hijacking remain dominant attacks, while persistent state corruption and multi-agent propagation are emerging threats; current defenses lack compositionality and benchmarks inadequately measure real-world agent security risks.

### [Your Agentic LLMs Secretly Encode Indirect Prompt-Injection Exposure in Hidden States](https://arxiv.org/abs/2608.02657)
*arXiv cs.AI · 8h ago · score 88*

This paper reveals that agentic LLMs leak detectable signals of indirect prompt injection (IPI) exposure in their hidden states, enabling linear probes to predict vulnerability with 0.90+ AUROC across multiple large models including GLM-5.2 and Kimi-K3. The authors propose a probe-gated defense mechanism that bridges a "knowledge-action gap" where models encode IPI signals but fail to act on them safely, achieving significant attack mitigation (34.6% to 0% success rate on Qwen3.5-27B) while preserving benign task performance.

### [SecOPD: Mitigating Adaptive Prompt Injections by On-Policy Distillation](https://arxiv.org/abs/2608.21500)
*arXiv cs.AI · 8h ago · score 82*

SecOPD introduces token-level feedback mechanisms for defensive fine-tuning against prompt injection attacks, achieving 9.0% attack success rate on adaptive injections compared to 94.0% for prior defenses. This addresses a critical vulnerability in AI agents accessing external data, with demonstrated generalization to unseen domains like tool-calling scenarios.

### [Same Payload, Different Channel: Measuring Trust Asymmetry in Tool-Using Language Models](https://arxiv.org/abs/2606.00566)
*arXiv cs.CR · 8h ago · score 82*

This research reveals a critical vulnerability in tool-using LLMs: they inconsistently apply safety controls based on the channel through which malicious content arrives (user input vs. tool metadata vs. tool output), with production models treating identical payloads differently depending on source. The finding that general-purpose models discount tool metadata threats while agent-native models do not presents a significant attack surface for adversaries targeting agentic AI systems and warrants immediate security hardening.
