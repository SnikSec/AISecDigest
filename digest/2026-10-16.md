### [My Credentials, Please: Detecting Filesystem Capability Laundering in MCP Servers at Scale](https://arxiv.org/abs/2610.22301)
*arXiv cs.CR · 11h ago · score 92*

This research reveals "filesystem capability laundering" vulnerabilities in Model Context Protocol (MCP) servers, where attacker-controlled tool arguments can access sensitive host files beyond their declared functionality, affecting 16.4% of 4,806 analyzed servers. The work demonstrates practical exploitation across multiple vulnerability layers and resulted in coordinated disclosure of 13 security advisories including CVEs in Anthropic's tooling, directly impacting AI agent security posture.

### [MCP Python SDK: Unbounded Session Accumulation in StreamableHTTP Transport Enables Resource Exhaustion](https://github.com/advisories/GHSA-84m7-p3x7-pcfv)
*GitHub Security Advisories · 19h ago · score 92*

The MCP Python SDK's StreamableHTTP transport in stateful mode (default) suffers from unbounded session accumulation where sessions never expire and failed sessions remain registered, allowing unauthenticated clients to exhaust server memory through repeated requests. This critical resource exhaustion vulnerability affects FastMCP 1.x, MCPServer 2.x, and related components in versions 1.8.0-1.29.1 and 2.0.0-2.1.1, requiring server restart to reclaim memory.

### [Approve What, Exactly? Effect Binding and Trusted Rendering for Agent Step-Up Authorization](https://arxiv.org/abs/2610.21063)
*arXiv cs.AI · 11h ago · score 85*

This research identifies critical vulnerabilities in AI agent approval mechanisms used for high-risk operations like financial transactions and file deletion, demonstrating twelve distinct attacks (decoy recipients, amount cancellation, label spoofing, etc.) against current approval systems including AP2, MCP, and major runtimes. The authors propose ASU (Agent Step-Up), a reference architecture using canonical effect descriptors and passkey-backed approval cards with formal verification, achieving significant security improvements and demonstrating the widespread failure of current approval binding across eight tested runtimes.

### [INFUSE: A Unified Surface Benchmark for Indirect Prompt Injection in Agentic Systems](https://arxiv.org/abs/2610.20776)
*arXiv cs.AI · 11h ago · score 82*

INFUSE introduces a comprehensive benchmark for evaluating indirect prompt injection attacks in LLM-based agentic systems, testing 19 LLM families across 40 realistic tasks with 56 attack scenarios injected through realistic interaction surfaces. The benchmark reveals significant vulnerability across models (3.2%-41.9% attack success rates) and demonstrates that prompt hardening substantially reduces attacks from 58.2% to 14.3%, providing critical evaluation methodology for agentic AI security.

### [Thinking in Graphs: Neo4j-Backed Exploit-Chain Reasoning for LLM Penetration-Testing Agents](https://arxiv.org/abs/2610.20902)
*arXiv cs.CR · 11h ago · score 82*

This paper presents ChainGraph, a pattern that enables LLM-based penetration-testing agents to reason about multi-step exploit chains using Neo4j graph databases rather than flat context windows, addressing the critical gap between how AI agents and human attackers reason about attack progressions. The system uses the Model Context Protocol to wire exploit-chain reasoning into agents, with findings, credentials, and assets as typed graph nodes, allowing detection of how isolated medium-severity vulnerabilities can combine into critical attack paths through credential capture and privilege escalation.
