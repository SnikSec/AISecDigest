### [(A)iSpy: Parasitic Trojans for Machine Learning Infrastructure](https://arxiv.org/abs/2607.17550)
*arXiv cs.CR · 11h ago · score 88*

AiSPY demonstrates a novel infrastructure-level Trojan attack that compromises ML systems by injecting malicious code into runtime computation graphs, enabling both confidentiality breaches (hyperparameter exfiltration) and integrity attacks (gradient amplification for backdoor poisoning). This research exposes a critical vulnerability in ML pipelines where the runtime execution environment is implicitly trusted despite extensive auditing of data/models, making it highly relevant for securing ML infrastructure against sophisticated supply-chain threats.

### [Illusion of Depth: Revealing Hidden Stereo Vision Vulnerabilities in Depth Estimation](https://arxiv.org/abs/2609.16336)
*arXiv cs.CR · 11h ago · score 85*

This research reveals a fundamental vulnerability in stereo vision systems used by autonomous vehicles, drones, and robots where attackers can manipulate depth estimation using simple repeating patterns without sophisticated ML techniques. The attack is demonstrated across commercial cameras (ZED2, RealSense D435), multiple stereo matching algorithms, and deep learning models, with real-world proof-of-concept showing emergency braking triggers in autonomous driving systems at highway speeds.
