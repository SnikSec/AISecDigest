*arXiv cs.CR · 14h ago · score 92*

Confused Deputy Attacks targeting AI accelerators represent a critical vulnerability class where malicious applications can trick specialized hardware (TPUs, etc.) into performing privileged operations by exploiting the semantic gap between accelerators and OS security mechanisms. The research demonstrates practical exploits affecting AI accelerators from major vendors across 128+ SoCs and 100+ million devices, with findings confirmed by vendor acknowledgment and CVE assignment.

*GitHub Security Advisories · 21h ago · score 92*

Langflow versions before 1.10.3 are vulnerable to OS command injection via arbitrary commands in MCP stdio server configuration, allowing unauthenticated RCE on the host through auto-login endpoints. ### [ASPIRE: Agentic Safety & Prompt Injection Red-teaming Engine](https://arxiv.org/abs/2610.08951)
*arXiv cs.CR · 14h ago · score 88*

ASPIRE is an automated red-teaming framework that discovers prompt injection vulnerabilities in LLM agents by systematically exploring the behavior space through an evolving security graph and exploit/explore strategies. This work is significant for security practitioners as it identifies indirect injection risks that existing automated defenses miss, particularly in agent-based systems that interact with external tools and untrusted content.

### [Package Hallucination Attacks on Coding Agents through Prompt Injection in Rule Files](https://arxiv.org/abs/2610.09264)
*arXiv cs.CR · 14h ago · score 88*

Researchers demonstrate "package hallucination attacks" where malicious prompts injected into shared rule files (like .cursorrules) can manipulate coding agents to replace legitimate dependencies with attacker-controlled packages. The PackHallu framework uses evolutionary optimization to craft transferable prompts that succeed across multiple LLMs and agentic frameworks, revealing a critical supply chain attack vector against autonomous code generation systems.

### [Hidden in Plain Sight: Benchmarking Agent Safety Against Decomposition Attacks with DECOMPBENCH](https://arxiv.org/abs/2606.13994)
*arXiv cs.CR · 14h ago · score 85*

DeCompBench introduces a benchmark that exposes a critical safety vulnerability in LLM-based agents: decomposition attacks where harmful tasks are broken into benign subtasks that individually bypass safety mechanisms but cumulatively achieve malicious goals. Experiments show state-of-the-art agents have significantly lower refusal rates on decomposed variants of harmful tasks compared to direct harmful requests, indicating existing safety evaluations inadequately assess this realistic adversarial pattern.

### [Langflow has Authenticated Cross-Project File Disclosure via Unscoped MCP Resource Handlers](https://github.com/advisories/GHSA-4hmc-cfm3-w43c)
*GitHub Security Advisories · 21h ago · score 82*

Langflow contains an authenticated authorization bypass in MCP resource handlers that allows users to read files from other users' projects by supplying crafted file URIs. This cross-user vulnerability affects v1.6.8 through v1.8.3 and requires only authentication to the victim's MCP endpoint, enabling arbitrary file disclosure across project boundaries.

### [Towards a Unified Misuse Monitoring Benchmark](https://arxiv.org/abs/2610.07089)
*arXiv cs.AI · 14h ago · score 82*

This paper presents a unified benchmark for monitoring LLM agent misuse, addressing both decomposition attacks (splitting harmful requests into innocuous sub-requests) and prompt injection attacks. The research develops formal trace-level monitoring methods and demonstrates that action-framed monitors significantly outperform content-based approaches, particularly against injection attacks, revealing limitations of classical position-blind metrics in evaluating monitor effectiveness.
