## AI Security (5)

### [Stealth Apart, Harm Together: Skill Cascading Attacks on Skill-Based Agent Systems](https://arxiv.org/abs/2609.30383)
*arXiv cs.AI · 14h ago · score 92*

This paper introduces "skill cascading attacks," a novel attack vector where malicious behavior is distributed across multiple modular skills in agent systems such that each skill appears benign individually but combines to cause harm—demonstrated through a pharmacy example where medications and alerts are progressively suppressed. The research presents SkillCascade, an automated red-teaming framework and benchmark of 213 test cases, revealing a critical safety gap in popular agent systems (OpenAI Claude, Codex) that focus on vulnerabilities within individual skills but overlook emerging risks from inter-skill interactions.

### [MetaPermit: Scalable and Auditable Access Control for AI Agents via LLM-Inferred Meta-Attributes](https://arxiv.org/abs/2609.31039)
*arXiv cs.CR · 14h ago · score 82*

MetaPermit proposes a novel access control framework for AI agents that separates semantic inference from security enforcement using LLM-inferred meta-attributes, addressing vulnerabilities in current tool authorization mechanisms that struggle with scalability and indirect prompt injection attacks. The approach uses compact, task-independent meta-attributes combined with auditable policy enforcement to enable more consistent and scalable authorization decisions compared to coarse-grained rules or inconsistent LLM-based judgments.

### [Region-Level Black-Box Defense Against Stealthy Embedding-Space Backdoors in CLIP](https://arxiv.org/abs/2609.31558)
*arXiv cs.CR · 14h ago · score 82*

This paper presents CLIPGuard, a black-box defense mechanism against embedding-space backdoor attacks targeting CLIP models, which operate by poisoning image-text pairs to implant stealthy triggers that corrupt joint embeddings rather than classifier outputs. The work is significant for security practitioners because it addresses a critical vulnerability in widely-deployed vision-language models while requiring only black-box access—a realistic threat model for production systems where model internals are unavailable.

### [FragToken: Amplifying LLM Inference Costs through Noncanonical Token Generation](https://arxiv.org/abs/2609.31552)
*arXiv cs.CR · 14h ago · score 82*

FragToken presents a novel resource-consumption attack exploiting non-canonical token representations to inflate LLM inference costs without proportional increases in visible output length, making detection harder than existing methods. The attack uses training-time techniques combining self-distillation and filtering to maintain model utility while inducing fragmented token generation across normal prompts.

### [From ASR to ASP: Evaluating Prompt Attack Vulnerabilities Against Open-Source LLMs](https://arxiv.org/abs/2505.14368)
*arXiv cs.CR · 14h ago · score 82*

Researchers demonstrate systematic prompt injection vulnerabilities affecting 14 open-source LLMs, introducing Attack Success Probability (ASP) as an improved metric that captures uncertain/inconsistent model behaviors beyond simple success/failure rates. A novel "hypnotism attack" achieves ~90% ASP against aligned models like StableLM2 and Mistral, indicating that moderately well-known LLMs may be more vulnerable than flagship models—critical for practitioners securing LLMs in regulated domains like healthcare and finance.
