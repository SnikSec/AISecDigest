*GitHub Security Advisories · 18h ago · score 82*

The meta-ads-mcp tool contains a critical unauthenticated Server-Side Request Forgery (SSRF) vulnerability in the `upload_ad_image` endpoint that allows attackers to forge requests to arbitrary URLs including internal metadata endpoints and RFC 1918 addresses.
