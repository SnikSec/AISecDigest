### [AI Slop and Hallucinations in Vulnerability Assessment: A Survey on Reasoning Failures and Trustworthy Mitigation](https://arxiv.org/abs/2608.25667)
*arXiv cs.AI · 13h ago · score 92*

This paper identifies "AI slop"—hallucinated vulnerabilities, incorrect patches, and false bug reports—as a critical trustworthiness issue when deploying LLMs in vulnerability assessment workflows. The research formalizes the root cause as the gap between causal-deductive security reasoning and LLM probabilistic generation, proposing active neuro-symbolic verification and evaluation benchmarks (CVE-Bench, Slop-Score) as defenses against these reasoning failures.

### [MCPHallu: Benchmarking Reasoning, Execution, and Memory Hallucinations in MCP Agents](https://arxiv.org/abs/2611.07689)
*arXiv cs.AI · 13h ago · score 85*

MCPHallu is a new benchmark that systematically evaluates hallucination vulnerabilities in LLM agents deployed through the Model Context Protocol, identifying four key failure modes (Branch Collapse, Unreachable Goal, Tool Misuse, Context Forgetting) across reasoning, execution, and memory dimensions. Evaluation of 14 frontier LLM agents reveals significant risks with agents averaging only 0.642 on the benchmark, particularly struggling with unreachable goals where they fail to recognize infeasible tasks and continue making tool calls—a critical concern for production MCP deployments.

### [MemForm: Benchmarking Memory Formation Poisoning in LLM Agents](https://arxiv.org/abs/2610.14431)
*arXiv cs.CR · 13h ago · score 82*

MemForm introduces a benchmark for systematically evaluating memory formation poisoning attacks against LLM agents across five critical interfaces (Content, Evidence, Scope, Selection, and Path), revealing that all tested interfaces are broadly susceptible despite agents learning from successful past interactions. This work demonstrates that adversaries can manipulate agent behavior through memory consolidation order and retention patterns alone, presenting a significant threat model for long-term autonomous LLM agent deployments.
