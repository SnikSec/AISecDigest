*arXiv cs.AI · 9h ago · score 82*

This research evaluates prompt injection vulnerabilities in agentic systems that maintain persistent memory across sessions, demonstrating that malicious payloads embedded in memory files can successfully attack current and future agent interactions. The study reveals that while agents resist overwriting their own memory with untrusted content, pre-planted payloads in persistent storage achieve high attack success rates, establishing persistent memory as a new attack surface requiring defensive measures.

### [MCP Python SDK: HTTP transports serve session requests without verifying the authenticated principal](https://github.com/advisories/GHSA-jpw9-pfvf-9f58)
*GitHub Security Advisories · 17h ago · score 82*

The MCP Python SDK's HTTP transports (SSE and Streamable HTTP) fail to verify that incoming requests are authenticated as the same principal that created a session, allowing attackers with a session ID to send messages regardless of bearer token. This affects only stateful HTTP deployments with authentication enabled, creating a privilege escalation risk where any known session ID can be hijacked for unauthorized API calls.
