### [Breaking MCP with Function Hijacking Attacks: Novel Threats for Function Calling and Agentic Models](https://arxiv.org/abs/2604.20994)
*arXiv cs.AI · 11h ago · score 92*

This paper introduces Function Hijacking Attacks (FHA), a novel vulnerability in agentic LLMs that forces models to invoke attacker-selected functions regardless of semantic context, achieving 62.5-81.9% attack success rates across multiple function-calling models. The attack's domain-agnostic nature, generalization to unseen queries, and cross-model transferability represent a critical threat vector for deployed agentic systems that security engineers must understand and defend against.

### [ECLIPSE: Self-Evolving Stealthy Prompt Injection Attack against Long-Horizon Agentic Systems](https://arxiv.org/abs/2608.30441)
*arXiv cs.CR · 11h ago · score 92*

ECLIPSE is a novel prompt injection framework that exploits long-horizon agentic LLM systems by combining stealthy direct user-prompt injection with indirect tool-side injection using workflow encoding and dynamic trajectory correction. This represents a sophisticated advancement in prompt injection attacks that achieves high success rates (96.7% on tasks requiring 5+ tool calls) while evading detection, making it highly relevant for understanding emerging vulnerabilities in autonomous agent deployments.
