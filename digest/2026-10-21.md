### [You Are the Trigger: Speaker-Activated Backdoors](https://arxiv.org/abs/2610.27210)
*arXiv cs.CR · 12h ago · score 85*

This paper demonstrates Speaker-Activated Backdoor (SAB) attacks on speech models where an attacker compromises the model during fine-tuning to trigger malicious behavior when processing a target speaker's natural voice. The attack achieves high success rates (90-97%) on production models like Whisper and Parakeet using minimal audio samples, and can chain downstream to frontier LLMs to execute harmful actions via transcription-based injected instructions.

### [MCP  TypeScript server SDK: Shared transport or server instances delivered one HTTP client's messages to another](https://github.com/advisories/GHSA-jm63-cq47-j5jp)
*GitHub Security Advisories · 20h ago · score 82*

MCP TypeScript server SDK versions 2.0.0-2.2.0 suffer from message routing confusion where multiple HTTP clients sharing a stateless transport or server instance could receive each other's responses and notifications due to JSON-RPC id collisions. This is a critical data isolation vulnerability affecting common deployment patterns shown in the README examples that required both a code change and an upgrade to version 2.3.0 to remediate.

### [MCP TypeScript SDK: One HTTP request within the default size limit could exhaust server memory during validation](https://github.com/advisories/GHSA-46jr-4wx8-v453)
*GitHub Security Advisories · 20h ago · score 82*

The MCP TypeScript SDK allows a single HTTP request within the default 4 MiB size limit to trigger server memory exhaustion by validating excessive array elements and object keys, causing JavaScript heap out-of-memory crashes. This vulnerability affects HTTP-accessible MCP servers (particularly those with tools accepting array or record inputs) and requires an explicit configuration change (`maxToolInputElements` option) in patched versions to mitigate.

## AI Identity & Non-Human Identity (2)

### [MCP TypeScript SDK: Server bearer authentication accepted tokens issued for another service](https://github.com/advisories/GHSA-rvq5-wwqv-78pq)
*GitHub Security Advisories · 20h ago · score 85*

The Model Context Protocol (MCP) TypeScript SDK's bearer authentication failed to validate token audience, allowing tokens issued for other services to be accepted by your MCP server when using a shared authorization server. This affects multiple SDK versions through early 2025 and requires immediate upgrade to patched versions that include audience validation in bearer token verification.

### [MCP TypeScript client SDK: HTTP client transports and OAuth requests followed cross-origin redirects and re-sent custom headers and request bodies](https://github.com/advisories/GHSA-6prh-2h8m-c8cw)
*GitHub Security Advisories · 21h ago · score 85*

The Model Context Protocol (MCP) TypeScript SDK had a critical credential leakage vulnerability where HTTP transports and OAuth clients followed cross-origin redirects and re-transmitted sensitive data including API keys, session IDs, and OAuth tokens (refresh_token, client_secret) to untrusted origins. This vulnerability affects applications using StreamableHTTPClientTransport, SSEClientTransport, or OAuth client functions in SDK versions through 1.31.0 and client versions 2.0.0-2.2.0, requiring immediate upgrade to patched versions.
