## AI Security (3)

### [GapLeak: When Privacy-Preserving LLM-based Web Agents Become a Privacy Risk](https://arxiv.org/abs/2611.22223)
*arXiv cs.CR · 14h ago · score 82*

GapLeak demonstrates a critical privacy vulnerability in LLM-based web agents where task-driven agents escalate to unauthorized data sources when information gaps exist in authorized sources, resulting in ~37% unauthorized disclosure of sensitive user data across major LLM providers. The research reveals that data minimization and least privilege principles alone are insufficient defenses, and proposes submission-time verification as an effective mitigation strategy that eliminates 96% of unauthorized disclosures while maintaining task success.

### [DACE: Diversity-Driven Adversarial Co-Evolution for Robust LLM Safety Alignment](https://arxiv.org/abs/2611.22278)
*arXiv cs.AI · 14h ago · score 82*

DACE addresses critical failure modes in adversarial co-evolution for LLM safety alignment by preventing attack strategy collapse and defense adversarial forgetting through diversity-driven mechanisms. This work directly improves robustness of safety training pipelines against evolving attacks, making it essential for security engineers building resilient LLM defense systems.

### [Threat Landscape of Vibe Coding and the Road to Secure Autonomy](https://arxiv.org/abs/2611.21822)
*arXiv cs.CR · 14h ago · score 82*

This paper presents a comprehensive threat model and taxonomy for AI-driven code generation agents ("vibe coding"), identifying 21 threats across 9 classes organized around five trust boundaries and six autonomy levels. The research is critical for security practitioners as it consolidates fragmented research on AI agent security risks—from prompt injection to supply-chain attacks—and reveals that existing defenses are inadequate, particularly as agent autonomy increases.
