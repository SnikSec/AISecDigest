## AI Security (4)

### [Measuring and Exploiting Implicit Trust in LLM Tool-Calling Pipelines](https://arxiv.org/abs/2609.18217)
*arXiv cs.CR · 11h ago · score 95*

Researchers demonstrate cross-channel fragmentation attacks against LLM tool-calling pipelines that evade existing defenses by distributing malicious payloads across multiple input channels (tool descriptions, results, prompts) without privilege separation. Despite frontier models being resistant to single-channel injections, the study reveals models like GPT-4o and Llama 70B achieve up to 100% credential exfiltration rates under multi-channel attacks, representing a critical unexplored attack surface in production LLM deployments.

### [Reflections on Trusting Trust, Revisited: Contaminating Self-Modifying AI Coding Agents with Poisoned Benchmarks](https://arxiv.org/abs/2609.17817)
*arXiv cs.AI · 11h ago · score 92*

This research demonstrates a critical vulnerability in self-modifying AI coding agents: adversaries can inject poisoned benchmarks into the agent's self-improvement loop to induce future agent versions to generate vulnerable code on clean tasks, successfully tested against Darwin Goedel Machine, Self-Improving Coding Agent, and Hyperagents. The attack parallels Thompson's classic compiler backdoor concept but applied to autonomous agent self-evolution, with contamination persisting even after retraining on clean benchmarks—representing a fundamental trust issue in agent-driven software development.

### [The Verifiable Action Card: Trustworthy Human-in-the-Loop Control for Secure Autonomous Agents](https://arxiv.org/abs/2609.18411)
*arXiv cs.CR · 11h ago · score 82*

This paper presents the Verifiable Action Card, an architectural defense against prompt injection and deceptive confirmation attacks in autonomous browser agents by rendering approval information out-of-band from trusted browser chrome. The work demonstrates complete mitigation of attack classes (68-100% baseline success reduced to 0%) that exploit human-in-the-loop safeguards, directly addressing a critical security gap in agentic systems operating under authenticated user sessions.

### [Safety Does Not Compose: Non-Decaying Loop State for Autonomous LLM Agents](https://arxiv.org/abs/2608.27141)
*arXiv cs.AI · 11h ago · score 82*

This paper identifies a critical safety composition failure in autonomous LLM agents: trajectory-scoped safety monitors reset between loop iterations, allowing adversaries to fragment attack evidence across multiple steps to evade detection. The authors present LoopHarness, a mechanism that maintains persistent, non-decaying safety state across agent loop iterations to bound unauthorized actions, addressing a fundamental architectural vulnerability in deployed autonomous agent systems.

### [When Agents Look Like Beacons: NIDS Evasion by Model Context Protocol Traffic](https://arxiv.org/abs/2609.19091)
*arXiv cs.CR · 11h ago · score 82*

This research demonstrates that Model Context Protocol (MCP) traffic used by AI agents structurally mimics C2 beaconing patterns and successfully evades standard enterprise NIDS/IDS detection systems (Suricata, RITA) across multiple TLS configurations. The findings reveal a significant detection gap where MCP's authenticated, high-frequency JSON-RPC communication over HTTP can operate undetected as a potential attack vector or C2 channel, requiring security engineers to develop new detection strategies.
