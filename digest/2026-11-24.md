### [ruflo MCP bridge allows unauthenticated remote code execution in default Docker Compose deployments](https://github.com/advisories/GHSA-c4hm-4h84-2cf3)
*GitHub Security Advisories · <1h ago · score 92*

An MCP bridge in ruflo's default Docker Compose deployment exposed unauthenticated remote code execution via POST /mcp endpoints, allowing attackers to execute arbitrary commands, extract API keys, and poison the AI output learning store for all users. The vulnerability was fixed by implementing loopback-only binding by default, Bearer authentication with constant-time comparison, and server-side tool execution gates for sensitive operations.
