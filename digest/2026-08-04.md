## AI Security (3)

### [Exposed by Design: A Dynamic Security Assessment of Internet-Facing MCP Servers at Scale](https://arxiv.org/abs/2608.00150)
*arXiv cs.CR · 9h ago · score 95*

This comprehensive security assessment reveals critical vulnerabilities in 414 internet-facing Model Context Protocol (MCP) servers, discovering 68 reportable issues including SQL injection, SSRF, prompt injection, and path traversal—with 91.8% lacking OAuth authentication. The findings highlight systemic security gaps in rapidly deployed agentic infrastructure, including 687 exposed shell execution tools and 41.6% server churn between measurements, indicating widespread production deployments without adequate security review.

### [Adversarial Attacks in Multi-Agent LLM Pipelines: Unveiling Structural Vulnerabilities in Agentic AI Architectures](https://arxiv.org/abs/2608.00718)
*arXiv cs.CR · 9h ago · score 92*

This research identifies a critical architectural vulnerability in multi-agent LLM pipelines where adversarial content accepted by one agent propagates as trusted input to downstream agents, due to missing boundary verification mechanisms. The findings demonstrate that these vulnerabilities are structural properties independent of model capability, affecting production deployments of GPT-4, Claude, and Kimi models across multiple attack vectors including content injection, agent impersonation, and memory poisoning.

### [Securing Agentic AI: From Per-Action Checks to Trajectory Assurance](https://arxiv.org/abs/2608.01558)
*arXiv cs.CR · 9h ago · score 85*

This paper addresses the security challenges of autonomous LLM-based agents operating within organizational and regulatory constraints, moving beyond per-action validation to ensure overall behavioral compliance with system-level rules and invariants. The work identifies a comprehensive threat landscape across single-agent attack surfaces (prompt injection, memory poisoning, tool exploitation), multi-agent delegation challenges (identity/trust/capability control), and systemic concerns (supply chain integrity, provenance, observability).
