### [`@dynatrace-oss/dynatrace-mcp-server` has Unauthenticated HTTP MCP Tool Invocation](https://github.com/advisories/GHSA-p7w7-4929-vpj5)
*GitHub Security Advisories · 20h ago · score 92*

The Dynatrace MCP server's HTTP transport mode allows completely unauthenticated access to tool invocations including sensitive operations like reading arbitrary Grail data and writing to tenant notebooks. This is a critical authentication bypass affecting any network-accessible instance running with the --http flag, enabling attackers to execute high-impact tools under the victim's Dynatrace credentials without any authorization headers.

## Offensive Security & AI Workloads (1)

### [@dynatrace-oss/dynatrace-mcp-server has a workflow template injection via create_workflow_for_notification](https://github.com/advisories/GHSA-xrmj-5g4g-8987)
*GitHub Security Advisories · 20h ago · score 82*

A template injection vulnerability in the Dynatrace MCP server's `create_workflow_for_notification` tool allows attackers to inject Jinja2 expressions that execute during workflow evaluation, enabling data exfiltration of event data to attacker-controlled destinations. The malicious workflow persists in the tenant after the MCP session ends, creating a long-lived backdoor for reconnaissance and lateral movement.
