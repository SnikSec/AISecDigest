### [Isolation as a First-Class Principle for LLM-Agent System Safety: Concepts, Taxonomy, Challenges and Future Directions](https://arxiv.org/abs/2607.12406)
*arXiv cs.AI · 11h ago · score 88*

This comprehensive survey reframes LLM-agent system safety around isolation as a core principle, establishing a taxonomy of five critical boundaries (user-agent, agent-tool, agent-execution, agent-agent, system-environment) where failures like prompt injection and tool misuse propagate. Security engineers implementing agent systems need this boundary-centric framework to identify where isolation breaks down and apply targeted defenses before compromise spreads across system components.

### [Context Inference Attacks Without Jailbreaks](https://arxiv.org/abs/2609.01663)
*arXiv cs.CR · 11h ago · score 82*

This research demonstrates that agentic AI systems leak sensitive context information through indirect inference attacks, even when protected by common mitigations like instructions against disclosure, logit suppression, and context dilution. The work formalizes context-inference attacks across multiple threat models and shows that benign user queries can expose exploitable signals about hidden sensitive data like healthcare records or financial documents loaded into the agent's context.

### [ACLE-MCP: Attested Capability Leases for Execution-Time Trust in Remote LLM Tool Use](https://arxiv.org/abs/2609.02690)
*arXiv cs.CR · 11h ago · score 82*

ACLE-MCP addresses a critical trust gap in remote LLM agent tool use where OAuth authorization doesn't guarantee that actual execution occurs on the intended provider-side workload. The proposed architecture uses short-lived, sender-constrained capability leases with workload attestation and execution-time admission controls to prevent post-authorization attacks like workload substitution and stale authority reuse.
