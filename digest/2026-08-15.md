### [Practice Makes Unsafe: Skill Misevolution in Self-Improving LLM Agents](https://arxiv.org/abs/2608.12851)
*arXiv cs.AI · 8h ago · score 82*

Self-improving LLM agents can develop and persist unsafe behaviors across tasks through skill evolution, where successful but unsafe trajectories become reusable policies that transfer to new contexts. The research demonstrates that existing benchmarks fail to capture this lifecycle risk, and proposes SkillMisevo-Bench and SafeEvolve to measure and mitigate unsafe skill artifacts across agent frameworks.

### [Sovereign by necessity? Frontier AI export controls, cyber security, and the limits of national AI capability](https://arxiv.org/abs/2608.13272)
*arXiv cs.AI · 8h ago · score 82*

Frontier AI export controls and capability concentration create geopolitical dependencies where access to advanced models is weaponized as state-level leverage, with demonstrated examples of US restrictions causing worldwide model withdrawals. The paper argues that sovereign AI capability is economically infeasible for most nations, forcing reliance on foreign frontier models while autonomous AI-enabled cyber campaigns simultaneously raise the stakes of access denial in national security contexts.

Token Optimizer MCP contains a critical OS command injection vulnerability (CWE-78) in the smart_user tool's get-user-info operation, allowing attackers to execute arbitrary commands through unsanitized username parameters passed to shell execution. This represents a direct attack vector for MCP clients to compromise the privileges of the MCP server process, making it a high-severity issue for any deployment using agentic workloads with this tool.
