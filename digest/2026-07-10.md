### [Demystifying LLM Supply Chain Vulnerabilities in the Wild: Distribution, Root Cause, and Real-World Impact](https://arxiv.org/abs/2502.12497)
*arXiv cs.CR · 9h ago · score 92*

This empirical study analyzes 529 real-world vulnerabilities across the LLM supply chain, finding that 18.5% are LLM-specific and concentrated in application and model integration layers with issues like improper model/prompt/dataset handling. The research correlates these vulnerabilities to 45.6% of 63,243 publicly exposed LLM services being remotely exploitable, with over 70% at critical or high severity, demonstrating concrete attack surfaces for model tampering and data exfiltration.

### [Heimdallr: Characterizing and Detecting LLM-Induced Security Risks in GitHub CI Workflows](https://arxiv.org/abs/2605.05969)
*arXiv cs.CR · 9h ago · score 92*

Heimdallr is the first systematic study of LLM-induced security risks in GitHub CI workflows, identifying how externally-controllable inputs can manipulate LLM-driven decisions affecting repository state and privilege execution. The framework has responsibly disclosed 802 vulnerable workflow instances, providing security engineers with concrete threat vectors and detection methodology for a critical intersection between LLM and CI pipeline security.

### [ARGUS: Defending LLM Agents Against Context-Aware Prompt Injection](https://arxiv.org/abs/2605.03378)
*arXiv cs.CR · 9h ago · score 85*

This paper introduces ARGUS, a causal-provenance auditing system designed to defend LLM agents against context-aware prompt injection attacks, a vulnerability that existing defenses fail to address. The work presents AgentLure, a benchmark for evaluating defenses on context-dependent agentic tasks, and demonstrates that ARGUS reduces attack success rates from 28.8% to 3.8% by verifying that proposed actions are grounded in benign evidence and causally justified.
