## AI Security (5)

### [What If Prompt Injection Never Left? Rethinking Agent Security through Cross-Session Stored Prompt Injection](https://arxiv.org/abs/2606.04425)
*arXiv cs.CR · 9h ago · score 92*

This paper introduces Cross-Session Stored Prompt Injection, a critical threat vector for agentic AI systems where malicious instructions persist in long-lived system state (memories, filesystems, tools) and influence future executions across multiple sessions. The research formalizes this threat model as distinct from traditional single-session prompt injection, provides a taxonomy of persistence mechanisms, and advocates for state-centric rather than interaction-centric security approaches for autonomous agents.

### [One Leak Away: How Pretrained Model Exposure Amplifies Jailbreak Risks in Finetuned LLMs](https://arxiv.org/abs/2512.14751)
*arXiv cs.CR · 9h ago · score 92*

This research demonstrates that jailbreak vulnerabilities in pretrained LLMs transfer effectively to finetuned variants, with adversarial prompts optimized on base models successfully targeting proprietary finetuned derivatives. The authors develop a Probe-Guided Projection attack that exploits transferability-relevant structure in pretrained representations, and propose a lightweight representation-level defense, revealing critical security risks in the standard pretrain-to-finetune development paradigm.

### [Piggybacking on Perception: Stealthy Concurrent Audio Prompt Injections against Multimodal LLM Agents](https://arxiv.org/abs/2607.28165)
*arXiv cs.CR · 9h ago · score 85*

This research demonstrates concurrent audio prompt injection attacks against multimodal LLM agents, achieving 69% attack success rate against Gemini 3 Pro by piggybacking malicious instructions onto environmental noise. The work introduces AudioAgentSecurity benchmark covering 8 real-world scenarios and proposes CADV, a defense mechanism using acoustic source separation and cross-modal consistency analysis to detect such attacks.

### [MemSecBench: Tracking Agent Memory Poisoning from Persistence to Consequence and Repair](https://arxiv.org/abs/2607.27080)
*arXiv cs.AI · 9h ago · score 82*

MemSecBench introduces a comprehensive benchmark for evaluating memory poisoning attacks against AI agents, demonstrating that malicious instructions persist in 84.2% of tested configurations and successfully execute in 50.3% of cases. This research is critical for security engineers as it systematically maps the attack surface across agent memory lifecycles and multiple backend configurations, directly informing defensive strategies for deployed agentic systems.
