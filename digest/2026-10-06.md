### [vLLM: Harmony tool continuations drop `cache_salt` — restoring a cross-tenant prefix-cache membership oracle](https://github.com/advisories/GHSA-935w-9g4m-p28p)
*GitHub Security Advisories · 17h ago · score 85*

vLLM's tool-continuation logic in the Harmony path drops the `cache_salt` parameter on re-submissions after tool calls, causing prefix cache entries to be cached in the global unsalted namespace instead of maintaining per-tenant isolation. This creates a cross-tenant prefix-cache membership oracle vulnerability where an attacker could infer information about other tenants' tool-assisted interactions by reconstructing and probing the unsalted continuation cache.

## AI Identity & Non-Human Identity (1)

### [MCP TypeScript SDK: OAuth client could send credentials to an authorization server chosen by the MCP server](https://github.com/advisories/GHSA-6qxp-vccf-f47h)
*GitHub Security Advisories · 1h ago · score 92*

The MCP TypeScript SDK's OAuth client fails to validate that authorization servers match their configured credentials, allowing a malicious MCP server to trigger credential disclosure to arbitrary servers without user interaction. This affects applications using the SDK's OAuth client (versions 1.12.0-1.30.1 for SDK and 2.0.0-2.1.0 for client) that connect to untrusted MCP servers, enabling credential theft including refresh tokens and client secrets.
