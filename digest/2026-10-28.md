## AI Security (6)

### [Log-To-Leak: Prompt Injection Attacks on Tool-Using LLM Agents via the Model Context Protocol](https://arxiv.org/abs/2610.36108)
*arXiv cs.AI · 13h ago · score 92*

Researchers demonstrate Log-To-Leak, a prompt injection attack exploiting the Model Context Protocol (MCP) metadata used by LLM agents to access external tools, achieving 62-100% success rates across tested configurations. The attack induces additional attacker-controlled tool calls that leak sensitive information (user queries, responses, agent context) while maintaining legitimate task completion, revealing a critical gap in current MCP security model with existing defenses remaining ineffective.

### [When AI Agrees Too Much: Manipulating Automated Code Review via Bias Injection](https://arxiv.org/abs/2603.18740)
*arXiv cs.AI · 13h ago · score 92*

Researchers demonstrate that LLM-based automated code review systems are vulnerable to framing effects and contextual-bias injection attacks, with novel LLM-assisted refinement attacks successfully re-introducing vulnerabilities in 97% of tested cases across real-world CI/CD pipelines. This represents a significant supply-chain attack vector where adversaries can manipulate PR metadata to bypass security defenses in widely-deployed code review tools like Claude Code and CodeRabbit.

### [AgentSentry: Mitigating Indirect Prompt Injection in LLM Agents via Temporal Causal Diagnostics and Context Purification](https://arxiv.org/abs/2602.22724)
*arXiv cs.AI · 13h ago · score 92*

AgentSentry proposes a novel inference-time defense against indirect prompt injection (IPI) attacks in tool-augmented LLM agents using temporal causal diagnostics and counterfactual re-executions to distinguish legitimate user intent from injected content. This work directly addresses a critical vulnerability class where attacker-controlled instructions embedded in external artifacts can trigger unauthorized actions across multi-turn agent interactions, providing practical mitigation beyond conservative blocking approaches.

### [MLflow CrewAI autologging records LLM provider API keys in logged trace spans](https://github.com/advisories/GHSA-j7qq-vr8c-xvw3)
*GitHub Security Advisories · 20h ago · score 92*

MLflow's CrewAI autologging feature inadvertently leaks LLM provider API keys into trace spans by serializing the agent object's string representation, which exposes plaintext credentials to MLflow backends and OTLP exporters. This is a critical credential exposure vulnerability affecting MLflow 3.16.0+ with CrewAI, where sensitive authentication material is transmitted without explicit user action, requiring immediate remediation to prevent unauthorized API access and billing fraud.

### [Anthropic's Unreleased AI Model Chains Flaws Into Working Chrome, Safari, Windows and Linux Exploits](https://thehackernews.com/2026/10/anthropics-unreleased-ai-model-chains.html)
*The Hacker News · 9h ago · score 85*

This research highlights both the potential for AI systems to accelerate vulnerability discovery and the importance of responsible disclosure practices, as Anthropic coordinated with vendors before disclosure and all flaws are now patched.

### [Detecting and Mitigating Query-Based System Prompt Leakage Attacks](https://arxiv.org/abs/2610.36295)
*arXiv cs.AI · 13h ago · score 82*

The work addresses a critical vulnerability where adversaries extract proprietary system prompts through multi-turn black-box interactions, achieving 97-99% detection F1 scores while maintaining low false positive rates.
