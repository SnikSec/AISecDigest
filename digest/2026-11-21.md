### [Safari MCP: JavaScript injection through single-quoted tool arguments (backslash not escaped)](https://github.com/advisories/GHSA-4rj4-rcrq-gr92)
*GitHub Security Advisories · 44h ago · score 85*

Safari MCP contains a JavaScript injection vulnerability in sixteen locations where tool arguments are unsafely embedded in single-quoted JavaScript strings without proper backslash escaping, allowing arguments with backslash-quote sequences to break out and execute arbitrary code. The vulnerability is particularly severe because it affects read-only tools exempt from tab-ownership checks, enabling an MCP client restricted to read-only operations to still execute arbitrary JavaScript in tabs it doesn't own.
