## AI Security (2)

### [Isolated but Exposed: Persistence-Based Memory Extraction Attack on LLM Agents](https://arxiv.org/abs/2607.23444)
*arXiv cs.CR · 9h ago · score 92*

SPORE represents a novel attack against LLM agents that exploits the tool interface to extract privacy-sensitive data from supposedly isolated long-term memory stores, bypassing user-level isolation defenses. The attack achieves 80% recovery of sensitive information by decoupling adversarial commands from retrieval anchors and persisting reactivation payloads across sessions, demonstrating a critical gap in agent security assumptions.

### [Just Testing, Move Along: Evasion of LLM-based System Log Interpretation by Prompt Injection](https://arxiv.org/abs/2607.24174)
*arXiv cs.CR · 9h ago · score 85*

This research demonstrates a critical vulnerability in LLM-based SOC log analysis systems: attackers can inject malicious prompts into log entries to cause the model to misclassify genuine cyber attacks as benign. The work presents a practical attack framework and shows that LLM explanations alongside classifications can serve as a detection mechanism for these adversarial manipulations.

### [Decentralized Granular Access Control for Agentic AI Systems in Critical Infrastructure](https://arxiv.org/abs/2607.22611)
*arXiv cs.AI · 9h ago · score 85*

This paper presents a decentralized, multi-layered access control framework specifically designed for autonomous AI agents in critical infrastructure, addressing security challenges that traditional RBAC cannot handle for stochastic agent behavior. The architecture introduces novel innovations including compound identity models, hierarchical permission systems, and progressive trust escalation with safety interlocks, grounded in OWASP LLM threat taxonomy and deployed at scale in production cloud infrastructure.
