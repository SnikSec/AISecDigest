### [claude-faf-mcp has an arbitrary local file read/write via unconfined `path` argument in FAF tools](https://github.com/advisories/GHSA-rr55-jp92-8wp2)
*GitHub Security Advisories · 17h ago · score 92*

The claude-faf-mcp tool suffers from path traversal vulnerabilities in its file read/write operations, allowing arbitrary file access outside intended project directories through unvalidated `path` arguments with no confinement beyond OS permissions. This vulnerability is particularly critical as it enables both file disclosure (SSH keys, credentials) and file modification, and can be exploited via MCP clients or LLM prompt injection attacks from attacker-controlled content.

### [faf-mcp has an arbitrary local file read/write via unconfined `path` argument in FAF tools](https://github.com/advisories/GHSA-j4r7-8ph4-43g3)
*GitHub Security Advisories · 17h ago · score 85*

faf-mcp's MCP tools fail to properly confine file access by resolving caller-controlled `path` arguments without restricting them to project directories, allowing arbitrary reads/writes via path traversal or absolute paths. This enables MCP clients or prompt-injected LLMs to exfiltrate sensitive files like SSH keys and credentials that the server process can access.

### [Task-Conditioned Least-Privilege Learning for Executable Terminal and MCP Agents](https://arxiv.org/abs/2608.18351)
*arXiv cs.AI · 8h ago · score 82*

This research demonstrates a post-training framework to enforce task-conditioned least-privilege access in LLM agents, reducing excess-authority errors from 4.56% to 0.79% on a 4B-parameter model across 2,896 evaluation episodes. The approach uses deterministic auditing across six risk dimensions and task-specific authority envelopes, directly addressing a critical security gap in agent authorization that traditional permission systems alone cannot solve.
