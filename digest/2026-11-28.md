### [GGUF LLM Models with Hidden Malware on Hugging Face Reached 2400 Victims](https://malspark.com/blog/malicious-gguf-models-hugging-face/)
*HN (agentic/LLM offsec, high-signal) · 7h ago · score 92*

Malicious GGUF format LLM models hosted on Hugging Face distributed malware to approximately 2400 victims, exploiting the model downloading mechanism as a supply-chain attack vector. This represents a critical threat to the ML development community as model weights repositories have become targets for embedding and distributing malicious code disguised as legitimate AI components.
