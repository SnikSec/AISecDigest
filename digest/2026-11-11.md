## AI Security (4)

### [From Attack Surface to Defense Architecture: Compositional Security for Agentic Coding Harnesses](https://arxiv.org/abs/2611.13960)
*arXiv cs.AI · 13h ago · score 92*

This paper presents ActiveSecHarness, a neurosymbolic reference monitor architecture designed to defend AI coding harnesses against injection attacks and living-off-the-land (LotL) exploitation where LLMs can weaponize system binaries through shell access. The work demonstrates that security in agentic systems requires structural architectural controls (capability tokens, taint tracking, OS-level guards) rather than relying on LLM-based content filtering, achieving perfect detection with zero false positives at microsecond latency compared to traditional approaches that degrade usability.

### [MIRAGE: Misleading Retrieval-Augmented Generation via Black-box and Query-agnostic Poisoning Attacks](https://arxiv.org/abs/2512.08289)
*arXiv cs.CR · 13h ago · score 92*

MIRAGE demonstrates a practical black-box, query-agnostic poisoning attack against RAG systems using surrogate model feedback and adversarial optimization techniques to inject misleading information into retrieval corpora. The attack's high transferability across different retriever-LLM configurations and ability to evade detection represent a significant threat requiring urgent defense mechanisms for production RAG deployments.

### [Microsoft Researchers Show AI Agents Can Be Backdoored by Editing Fewer Than 10 Neurons](https://thehackernews.com/2026/11/microsoft-researchers-show-ai-agents.html)
*The Hacker News · 11h ago · score 92*

Microsoft researchers demonstrated that AI agents can be compromised through surgical backdoor insertion by modifying fewer than 10 neurons without retraining, enabling arbitrary command execution when a trigger is activated. This attack is particularly critical for agentic systems since compromised models execute actions with the agent's own permissions, representing a severe supply-chain and post-deployment security risk for organizations deploying AI agents.

### [SGLang RCE Exploit Breaches NEAR AI, Steals Data From 18 Agents and About 100 Users](https://thehackernews.com/2026/11/sglang-rce-exploit-breaches-near-ai.html)
*The Hacker News · 23h ago · score 92*

This incident demonstrates the critical security risks of deploying inference engines with unpatched RCE flaws, particularly when processing confidential requests including those in TEEs.

*arXiv cs.CR · 13h ago · score 92*

BypassGym is a new benchmark that evaluates AI agents' ability to generate EDR-evasion loaders for executing payloads without detection, demonstrating that even lightweight LLM models like DeepSeek-V4.1 Flash can successfully bypass endpoint defenses in real Windows environments. This work highlights a significant capability gap in endpoint detection and response systems against AI-driven offensive operations, with practical implications for both defenders and the threat landscape.
