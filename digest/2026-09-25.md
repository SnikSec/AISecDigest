### [Persistent Billable State: Denial-of-Wallet Attacks and Defenses in Tool-Calling LLM Agents](https://arxiv.org/abs/2609.28585)
*arXiv cs.AI · 12h ago · score 85*

This paper identifies "denial-of-wallet" attacks where malicious or compromised tools in LLM agents can manipulate persistent state across turns to cause victims to be billed repeatedly without authorization, demonstrating up to 14,293x cost amplification across sessions. The research provides systematic analysis of this post-admission threat lifecycle and proposes host-side defenses including history compression and invariants to bound spending, establishing this as a critical financial security concern for production tool-calling agent systems.

### [On the Effectiveness of Kernel-Level Evidence for Agent Security](https://arxiv.org/abs/2609.28915)
*arXiv cs.AI · 12h ago · score 82*

This paper presents the first comprehensive study pairing kernel-level syscall traces with application-layer telemetry to detect malicious LLM agent behaviors, introducing the Agent Cross-Layer Evidence (ACE) corpus with 4,047 sessions across 17 threat models. The work demonstrates that kernel-level signals complement application-layer evidence to detect threats that operate below the application boundary, achieving better detection accuracy through multi-layer analysis than single-layer approaches.

### [Scanning the Harness: A Repository Study of Configuration Exposures in AI Coding Agents](https://arxiv.org/abs/2609.07360)
*arXiv cs.CR · 12h ago · score 82*

This repository study examines configuration exposures in AI coding agents across 3,171 public GitHub repositories, finding that 15.4% of agent setups contain security issues including unpinned MCP packages (9.8%), overly broad execution grants (2.5%), and excessive skill tool preapproval (3.8%). The research provides concrete evidence for supply chain risks in agentic AI systems and offers actionable recommendations for dependency pinning, execution permission review, and component conformance checks before distribution.
