### [LoginTrap: Uncovering Task-Agnostic Phishing-Style Indirect Prompt Injection Attacks against LLM-based Web Agents](https://arxiv.org/abs/2608.04741)
*arXiv cs.CR · 9h ago · score 92*

LoginTrap demonstrates a novel attack vector where malicious webpage content can trick LLM-based web agents into performing login actions and exfiltrating user credentials through task-agnostic indirect prompt injection. The attack achieves 86% success rate across different LLM backends and agent architectures, revealing a critical authentication boundary vulnerability in autonomous web agents that warrants immediate defensive research.

### [SoK: How Frontier AI Reshapes System-Level Security Risk Dynamics in Critical Infrastructure](https://arxiv.org/abs/2608.04033)
*arXiv cs.CR · 9h ago · score 85*

This SoK paper presents a novel framework for understanding how frontier AI systems reshape security risk dynamics in critical infrastructure through five dimensions: capability emergence, infiltration pathways, cross-system propagation, control authority degradation, and institutional response strain. The work identifies structural mismatches between academic AI-security research and operational CI constraints, providing a systems-level view beyond traditional threat enumeration that is directly relevant to how AI integration fundamentally changes infrastructure security posture.

### [Cross-Layer Semantic Flow Reconstruction for Attack Detection in Agentic Systems](https://arxiv.org/abs/2603.04469)
*arXiv cs.CR · 9h ago · score 82*

This paper introduces AScope, a framework that detects attacks in agentic systems by correlating application-level agent behavior with kernel-level audit events to reconstruct cross-layer semantic flows. The approach addresses a critical security gap where malicious intent may not be visible at the application layer alone but becomes observable through downstream OS-level execution effects, achieving strong detection performance on multi-agent scenarios.
