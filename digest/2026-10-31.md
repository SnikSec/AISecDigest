### [Where You Inject Matters: The Trust Region Effect in LLM Agents](https://arxiv.org/abs/2610.38867)
*arXiv cs.AI · 12h ago · score 85*

This paper reveals a critical vulnerability in LLM agents called the "trust region effect," where agent susceptibility to prompt injection attacks varies significantly based on injection placement rather than just content—for example, GPT-4 follows unsafe instructions in documentation files 2.6× more often than in code/data files. Security engineers must understand that agents implicitly trust certain environmental surfaces more than others, and attackers can exploit this by strategically placing injections in high-trust regions rather than just crafting better malicious content.

### [How Deterministic SAST and AI Security Agents Divide the Work: Coverage, Harness Policy and Cost in Snyk VulnBench 2.0](https://arxiv.org/abs/2610.38617)
*arXiv cs.AI · 12h ago · score 82*

VulnBench 2.0 empirically compares deterministic SAST tools against AI security agents on detecting attacker-reachable vulnerabilities, finding complementary strengths with deterministic and AI-driven approaches catching different vulnerability classes. The research demonstrates that neither approach is sufficient alone—combining Snyk Code (82.4% recall) with Claude Code (79.3% recall) achieved 93.5% detection on a curated benchmark of 108 vulnerabilities across multiple languages, with significant gaps driven by harness policy rather than model capability alone.
