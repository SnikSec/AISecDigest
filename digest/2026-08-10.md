## AI Security (4)

### [SkillJack: Persistent Skill Backdoors in Self-Evolving Agents](https://arxiv.org/abs/2608.03509)
*arXiv cs.CR · 8h ago · score 92*

SkillJack introduces a novel attack on self-evolving agents that poisons their experience-to-skill pipeline, allowing attackers to implant persistent malicious behaviors that bypass safety detection by becoming reusable skill artifacts. This represents a fundamental new threat vector where poisoned experiences transform into durable behavioral backdoors that survive removal of source records and evade detection at rates exceeding 88%, making it critical for security engineers building or deploying agent systems with skill persistence mechanisms.

### [From Documentation to Zero-day Vulnerabilities: LLM-Driven Fuzzing of JavaScript Engines in PDF Readers](https://arxiv.org/abs/2608.06641)
*arXiv cs.CR · 8h ago · score 88*

PDFuzzer demonstrates how LLMs can be weaponized for vulnerability discovery by automatically generating complex API call sequences in PDF readers, uncovering 31 zero-day vulnerabilities including arbitrary code execution flaws. This research highlights both the offensive potential of LLM-driven fuzzing techniques and the need for security teams to understand how AI-augmented fuzzing can bypass traditional testing limitations that rely on simple, isolated test cases.

### [LoRAScan: Detecting Backdoor Prompts in Low-Rank Adapters for Large Language Models via Down-Projection Activation Spikes](https://arxiv.org/abs/2608.06795)
*arXiv cs.AI · 8h ago · score 82*

LoRAScan introduces the first adapter-aware defense mechanism that detects backdoored LoRA adapters at inference time by identifying trigger-bearing inputs through anomalous activation spikes in down-projection layers, without requiring adapter modification. This addresses a critical supply-chain vulnerability where untrusted LoRA adapters could inject harmful outputs through hidden triggers, providing practical protection for organizations deploying third-party LLM specializations.

### [When Coordination Becomes a Threat: Communication Attacks in LLM-Controlled Multi-Robot Systems](https://arxiv.org/abs/2608.06830)
*arXiv cs.CR · 8h ago · score 82*

This work identifies critical communication vulnerabilities in LLM-controlled multi-robot systems, demonstrating that attackers can inject malicious instructions achieving 88-100% unsafe action rates across different system architectures. The research is highly relevant to security engineers as it exposes a significant gap in multi-agent AI security where coordination mechanisms become attack surfaces, with proposed mitigations like the Claim Provenance and Verification Gate offering practical defense mechanisms.
