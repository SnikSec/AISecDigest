### [Towards a Risk Assessment of Malicious Skill Files in Coding Agents](https://arxiv.org/abs/2608.05223)
*arXiv cs.CR · 8h ago · score 92*

This paper presents a novel attack vector against autonomous coding agents through malicious skill files—dynamically loaded instruction sets—demonstrating 95.5% exploitation rates against enterprise agents like Gemini CLI. The research provides a reproducible evaluation framework and benchmark of 2,826 adversarially synthesized skills mapped to MITRE ATT&CK tactics, representing a critical security gap that enterprises must address before deploying agentic systems in production environments.

### [LLMs Cannot Reliably Judge (Yet?): A Comprehensive Assessment on the Robustness of LLM-as-a-Judge](https://arxiv.org/abs/2506.09443)
*arXiv cs.CR · 8h ago · score 85*

LLM-as-a-Judge systems, widely used for automated evaluation and red teaming, are vulnerable to adversarial attacks that can manipulate evaluation outcomes, with the RobustJudge framework demonstrating that current defenses remain largely ineffective across 15 attack methods tested. This research highlights critical robustness gaps in deployed judge systems and reveals that prompt template design and model selection significantly impact vulnerability, creating immediate security implications for AI evaluation pipelines.

### [Breaking Customized LLMs for Coding: Automated Red Teaming for Instruction Backdoor Attacks](https://arxiv.org/abs/2608.05659)
*arXiv cs.CR · 8h ago · score 82*

ARIA is an automated red-teaming framework that demonstrates how to craft stealthy backdoored instructions for customized LLMs used in code intelligence tasks, achieving 94.5% attack success rates while evading detection. This research exposes a critical vulnerability in LLM customization platforms that rely on system prompt injection without parameter modification, highlighting the need for instruction-level validation and filtering mechanisms in production deployments.
