### [NetInjectBench: Benchmarking Indirect Prompt Injection in Tool-Using Large Language Model Agents for Network Operations](https://arxiv.org/abs/2607.10490)
*arXiv cs.CR · 9h ago · score 87*

This research introduces NetInjectBench, a 130-scenario benchmark evaluating indirect prompt injection attacks against tool-using LLM agents in network operations contexts, demonstrating that naive implementations suffer 82.5% unsafe action rates while metadata-aware policy gates can reduce this to effectively 0% while preserving functionality. The findings establish that LLM agents handling untrusted inputs (tickets, logs, alerts) in critical infrastructure require both prompt-level defenses and execution-time authorization boundaries to prevent compromise.

### [Rethinking MCP Security: A Large-Scale Study of Runtime MCP Servers and Security Scanner Reliability](https://arxiv.org/abs/2607.11086)
*arXiv cs.CR · 9h ago · score 82*

This large-scale study presents MCPZoo, a dataset of 64,611+ MCP servers enabling the first ecosystem-wide security assessment of the rapidly-adopted Model Context Protocol standard for LLM agent integration. The research reveals that existing security scanners produce unreliable threat signals (reporting 96.89% of servers as risky despite manual validation findings), highlighting critical gaps in how MCP server security is measured and assessed in production environments.

### [New MemGhost Attack Plants Persistent False Memories in AI Agents Through One Email](https://thehackernews.com/2026/07/new-memghost-attack-plants-persistent.html)
*The Hacker News · 23h ago · score 82*

The MemGhost attack demonstrates a novel persistence threat where a single email can inject false memories into AI agents with inbox access, causing them to internalize and act on fabricated information in subsequent sessions. This attack is particularly concerning because it's stealthy—users remain unaware their agent's behavior has been compromised, making it difficult to detect via normal observation.

### [Mako: A Self-Evolving Agentic Operating System (SE-AOS) for Autonomous Web Exploitation](https://arxiv.org/abs/2607.11288)
*arXiv cs.AI · 9h ago · score 92*

Mako is a Self-Evolving Agentic Operating System (SE-AOS) that autonomously discovers and exploits web vulnerabilities by evolving its own exploit capabilities at runtime, achieving 100% success on a 104-target benchmark spanning 26 vulnerability classes. This represents a significant advancement in autonomous exploitation techniques where the limiting factor shifts from reasoning to capability discovery, with potential implications for both offensive security testing and vulnerability research methodologies.

### [Agent Hacks Agent: Autoresearch for Production-Agent Red-Teaming](https://arxiv.org/abs/2607.11698)
*arXiv cs.AI · 9h ago · score 82*

This paper presents AHA, an automated red-teaming framework that discovers and catalogs reusable vulnerabilities in production LLM agents like Claude Code and Codex through a systematic hypothesis-testing loop. The approach builds a Vulnerability Concept Graph that captures the enabling conditions and attack surfaces for unsafe agent behaviors, demonstrating significant transferability across different models and attack scenarios—critical for proactive defense of agentic systems operating on untrusted content.
