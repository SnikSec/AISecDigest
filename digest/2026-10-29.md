### [mcp-sanitizer: URL sanitizer allows localhost/IPv6 loopback SSRF bypass via explicit port or bracketed IPv6](https://github.com/advisories/GHSA-4mfg-r38w-w8fg)
*GitHub Security Advisories · 21h ago · score 85*

The mcp-sanitizer library fails to block SSRF attacks when localhost/IPv6 loopback addresses include explicit ports or bracketed IPv6 notation, allowing attackers to bypass URL validation and reach internal services. This is critical because mcp-sanitizer is designed to gate MCP tool parameters like web_fetch and web_scraper before outbound requests, so this bypass directly enables internal service discovery and data leakage.
