### [Code Graph RAG: MCP paginated read_file path traversal / arbitrary file read](https://github.com/advisories/GHSA-vvr2-h2jp-838m)
*GitHub Security Advisories · <1h ago · score 85*

A path traversal vulnerability in Code Graph RAG's MCP `read_file` tool allows arbitrary file read on the server when pagination parameters (offset/limit) are used, exploiting Python's pathlib behavior with absolute paths. This is a critical security flaw affecting agentic workloads that rely on the MCP server, as attackers can read sensitive files like /etc/passwd without proper authorization.

### [tsParticles: Unbounded HTTP Request Body Buffering in @tsparticles/mcp-server Leads to Remote DoS](https://github.com/advisories/GHSA-447x-qqwf-m7xq)
*GitHub Security Advisories · <1h ago · score 85*

@tsparticles/mcp-server contains an unbounded HTTP request body buffering vulnerability in the POST /mcp endpoint that allows unauthenticated remote attackers to exhaust server memory and cause denial of service by streaming arbitrarily large payloads. The official Docker image is vulnerable by default as it runs with HTTP mode enabled on port 3000, requiring no special configuration for exploitation.
